# FastFleet Backend

The backend of FastFleet provides APIs for vehicle management, driver management, maintenance management, database operations, and future analytics and machine learning features.

## Technology Stack

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Pydantic
- Uvicorn
